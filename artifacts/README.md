# Hồ sơ thực nghiệm

- `data_audit.json`: thống kê và kiểm tra bộ dữ liệu.
- `environment.json`: môi trường chạy thực nghiệm.
- `full_run_metadata.json`: cấu hình, thời gian và trạng thái lần chạy đầy đủ.
- `training/history.csv`: lịch sử huấn luyện hai giai đoạn.
- `training/learning_curves.png`: đường học của mô hình.
- `deployment_verification.json`: phạm vi kiểm tra truy cập demo ngày 05/10/2026.

Các bảng kết quả và checksum được lưu riêng tại `results/final/`.
