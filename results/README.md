# Kết quả

Nguồn kết quả cuối là [final/](final/), gồm metric của 49 điều kiện, dự đoán từng ảnh, kiểm định thống kê và phân tích lỗi.

- `validation_tuning_all.csv`, `validation_tuning_best.csv`: kết quả chọn tham số trên Validation.
- `image_quality_results_49_conditions.csv`: bảng chất lượng ảnh.
- `dataset_summary.csv`, `data_validation.json`, `bad_images.csv`: thống kê và kiểm tra dữ liệu.
- `eda_sample_metrics.csv`: thống kê ảnh phục vụ phân tích khám phá.
